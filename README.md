# Maven Fuzzy Factory Business Performance Dashboard

An end-to-end business analytics project exploring sales, marketing, product performance, and refunds for Maven Fuzzy Factory using **Excel** and **Power BI**.

## Project Overview

This project transforms raw e-commerce data into interactive dashboards that help answer key business questions:

- How is the business performing over time?
- Which products generate the most revenue and profit?
- Which marketing channels drive the best conversions?
- Are refunds becoming a business concern?

## Tools

- Microsoft Excel (EDA & Pivot Tables)
- Power BI
- DAX

## Dashboard Features

### Power BI Dashboard
- Executive KPI cards
- Revenue & Order Trends
- Conversion Rate Trend
- Refund Rate Trend
- Marketing Channel Performance
- Traffic Source Distribution
- Interactive slicers (Year, Month, Product)

### Excel Dashboard
- Quick business performance overview
- Exploratory analysis
- KPI summaries

## Key Insights

- Revenue and orders showed consistent growth over time.
- Conversion rate improved from ~3% to over 8%.
- Google Search generated the most traffic, while Bing achieved the highest conversion rate.
- Revenue is highly concentrated in **Mr. Fuzzy**, creating dependency risk.
- Overall refund rate remained low (4.4%), despite temporary spikes.
